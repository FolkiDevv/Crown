# Proposal

> **Категория:** скорость (размер загрузки и места на диске) · **Приоритет:** низкий · **Проверка:** подтверждено по
> собранному release-APK · **Код:** upstream (шаг сборки) · **Объём:** S

## Why

### Находка
Почти 12 % APK занимает один файл, который на Android не нужен: цветной эмодзи-шрифт встроенного веб-дашборда sing-box.

Разбор release-APK этого коммита (`Crown-1.0.0-arm64-v8a.apk`, 47,9 МБ, `unzip -lv`):

| Файл | Сжато в APK | Распаковано |
|---|---|---|
| `lib/arm64-v8a/libthrone.so` (ядро) | 29,9 МБ | 85,2 МБ |
| `resources.arsc` (хранится без сжатия) | 6,1 МБ | 6,1 МБ |
| `assets/sb-dashboard/assets/noto-color-emoji-emoji-400-normal-*.woff2` | **5,69 МБ** | 5,71 МБ |
| `classes.dex` | 4,5 МБ | 10,4 МБ |
| остальной `assets/sb-dashboard/` | 1,0 МБ | 2,5 МБ |

Дашборд скачивается при сборке целиком (`.github/actions/sing-box-dashboard/action.yml`, тот же шаг в
`buildScript/fdroid/prebuild.sh`). Пост-обработка `buildScript/dashboard_css.py` правит только media-запросы CSS. Шрифт
подключён в `assets/index-*.css` правилом `@font-face { font-family: Noto Color Emoji; src: url(./noto-color-emoji-….woff2) }`
без `unicode-range` и перечислен в списке предзагрузки service worker'а `sw.js`. woff2 уже сжат (5 708 560 → 5 688 296
байт), поэтому deflate в APK его не уменьшает.

Шрифт нужен вебу на системах без цветных эмодзи (флаги стран на Windows). Системный шрифт эмодзи Android — тот же Noto
Color Emoji, поэтому в WebView приложения подмена на системный шрифт ничего не меняет.

Остальные статьи близки к минимуму. Ядро — отдельная сборка. `androidResources.localeFilters` дал бы 0,2–0,4 МБ
(строки ~65 лишних локалей библиотек). `useLegacyPackaging = true` (`app/build.gradle.kts:39-43`) — осознанный
компромисс: APK для скачивания вдвое меньше ценой распаковки библиотеки на диске.

### Влияние
- Каждое обновление скачивает полный APK, и 5,7 МБ из ~48 МБ приходятся на этот шрифт. Для мобильной сети и частых
  превью это 12 % трафика каждого обновления.
- Место на устройстве: 5,7 МБ в APK и ещё 5,7 МБ после распаковки дашборда во внутреннюю память
  (`bg/SingBoxDashboard.kt`, один раз на установку).
- На работу VPN и время старта не влияет.

### Как воспроизвести
1. `unzip -lv Crown-<версия>-arm64-v8a.apk | sort -k3 -n -r | head`: третьим по размеру идёт
   `assets/sb-dashboard/assets/noto-color-emoji-…woff2`.
2. Проверка, что шрифт не нужен: во временной сборке удалить файл, правило `@font-face` из `assets/index-*.css` и запись
   из `sw.js`. Открыть дашборд в приложении (страницы прокси и соединений с флагами стран). Эмодзи и флаги рисуются
   системным шрифтом WebView, в консоли WebView нет ошибок установки service worker'а.

Шаг 2 выведен из кода и содержимого APK и не прогонялся.

## What Changes
1. **Рекомендуется:** в шаге подготовки дашборда (рядом с вызовом `dashboard_css.py` в
   `.github/actions/sing-box-dashboard/action.yml` и в `buildScript/fdroid/prebuild.sh`) удалять
   `assets/noto-color-emoji-*.woff2`, его правило `@font-face` в CSS и его запись в `sw.js`. Проверку «файла нет,
   ссылок на него нет» лучше сделать частью скрипта, чтобы сборка падала при смене имени или формата в новой версии
   дашборда, как это уже делает `dashboard_css.py` для media-запросов. Выигрыш −5,7 МБ на APK каждой ABI.
2. По желанию: `androidResources { localeFilters += <20 локалей приложения> }` — ещё −0,2–0,4 МБ.
3. Дороже и только если дашборд редко нужен: скачивать его по требованию при первом открытии. Это M, и отдельное решение.

Как проверить: размер APK до и после в шаге сборки CI (печатать размер). Ручная проверка страниц дашборда.

### Modified Capabilities
- `repository-governance`: если владелец хочет закрепить, — требование к сборке «в APK не попадают веб-шрифты дашборда,

## Impact
- **Код:** `.github/actions/sing-box-dashboard/action.yml`, `buildScript/dashboard_css.py` (или новый скрипт рядом),
  `buildScript/fdroid/prebuild.sh`; для п. 2 — `app/build.gradle.kts`.
- **Upstream:** шаг сборки дашборда — код upstream, его нет ни в `TOUCH_POINTS`, ни в `FORK_IDENTITY_POINTS`. Нужна новая
  точка правки (или патч upstream: экономия полезна и ему). `app/build.gradle.kts` — существующая точка правки 2, но её
  назначение — Compose и simple. Для `localeFilters` её описание нужно расширить.
- **Ядро throne, сборка, инструменты:** только сборка; ядро не затрагивается.
- **Риски:** забыть запись в `sw.js` — тогда установка service worker'а падает на отсутствующем файле. Дашборд при этом
  открывается (его раздаёт ядро локально), но с ошибкой в консоли. Новая версия дашборда может переименовать шрифт,
  и проверка в скрипте должна это ловить. На очень старых WebView флаги стран могут стать буквами регионов.
- **Проверка исправления:** размер APK в CI; ручная проверка дашборда на Android 8 и 16.
