## Пробелы

Нет доказательства:

- **26** (simple-ui, «Автообновление выключено пользователем»): правило есть только в коде (f6f5d159, батч 10), его не проверяли ни на устройстве, ни unit-тестом. Нужна проверка на устройстве: выключить «Автообновление подписок» → добавить подписку → переключатель остаётся выключенным, в сводке нет пункта об обновлении.
- **72** (traffic-modes, «Обычная сеть, работает только сервер для белых списков») и **74** («Белые списки, серверы для белых списков не отвечают»): запасной уровень управляемых авто-селекторов (стратегия `priority` ядра, D5) не проверялся. Unit-тестом это не покрыть: выбор делает ядро. Нужна проверка на устройстве с фикстурой подписки: обычные серверы на неотвечающих адресах и один рабочий сервер с ключевым словом в имени (и наоборот для сети с белыми списками).

Частично:

- **46** «Зарубежный домен на российском IP»: подтверждено только кодом (профиль upstream берётся без изменений, своих правил нет).
- **48** «Разрешение адреса сервера»: прямой DNS профиля «Белые списки» = `whitelistDns` подтверждён кодом и unit-тестом; подключение к серверу с доменным именем при недоступных зарубежных DNS на устройстве не проверялось.
- **71** «Автовыбор · Обычная сеть»: уровень «только обычные серверы» подтверждён unit-тестом, а то, что выбран именно обычный сервер, на устройстве отдельно не зафиксировано.
