# Proposal

## Why

Текущий интерфейс рассчитан на опытных пользователей: боковое меню из 11 пунктов, 26 протоколов в меню «Добавить», 12 разделов настроек (Mux, uTLS, окна QUIC и т. п.). Неопытный пользователь не получает ответа на три главных вопроса — «я защищён?», «через какой сервер?», «почему не работает?» — и не может сам починить типовые проблемы. Почти все нужные механизмы уже есть в ядре и приложении (авто-селектор с уровнями, URL/IP/service-тесты, снимок маршрутных профилей с набором `Profile_Russia`, сведения о подписке, редактор журналов без секретов), поэтому задача — новый слой интерфейса и правильные значения по умолчанию, а не переписывание логики. Дополнительно в мобильных сетях РФ действуют белые списки, при которых нужен отдельный режим маршрутизации, а приложение их не распознаёт.

Макет согласован с владельцем репозитория: https://claude.ai/artifact/MBZej488jTBbJnqAXtHAv5

## What Changes

- **BREAKING (UX)**: по умолчанию (и при новой установке, и после обновления) открывается новый упрощённый интерфейс. Классический интерфейс сохраняется целиком; переключение доступно в обе стороны, выбор запоминается. После обновления новый интерфейс один раз показывает подсказку, как вернуться к классическому.
- Новый интерфейс: три раздела (Главная, Серверы, Настройки) с адаптивной навигацией для телефона, планшета/складного и Android TV.
- Главная: одна кнопка подключения с понятными состояниями и две карточки — текущий сервер и текущий режим трафика.
- Универсальное добавление: одна точка входа (буфер обмена, QR, ссылка, файл), формат определяется автоматически, выбора протокола нет. При открытии приложение предлагает импортировать подписку/ссылку из буфера обмена. На первом экране нет WARP.
- После импорта подписки сразу включаются автовыбор сервера, ежедневное автообновление подписки и режим «Авто».
- Список серверов: «Авто» сверху; подписки — по странам; добавленные вручную — плоским списком; серверы для белых списков — отдельным разделом под основными. Протоколы, адреса и порты скрыты.
- Режимы трафика: «Авто» (по умолчанию), «Умный» (российские ресурсы напрямую), «Белые списки» (весь трафик через VPN, включая российские ресурсы), «Только выбранные приложения».
- «Авто» сам определяет белые списки в текущей сети проверкой в обход туннеля и переключает маршрутизацию и выбор сервера; о смене режима сообщает только карточка на главной (без уведомлений).
- Серверы для белых списков распознаются только по ключевым словам в названии; пользователь не может изменить это решение.
- Списки адресов для проверки сети и ключевые слова поставляются вместе с приложением и обновляются тем же механизмом, что и маршрутные профили (RouteRepo).
- «Починка»: универсальная функция диагностики и исправления — запуск акцентной кнопкой вверху «Настроек» и из баннера проблемы на главной; 11 последовательных проверок (сеть, белые списки, время, частный DNS/другие VPN, DNS напрямую, подписка, серверы, DNS через VPN, сайты через VPN, российские сайты напрямую, работа в фоне); безопасные исправления выполняются автоматически; итог — «исправили сами», «причина найдена» с инструкцией или «причина неизвестна» с экспортом отчёта.
- Экспорт отчёта для специалиста (zip через системное «Поделиться») без паролей, ключей, UUID, адресов серверов и ссылок подписок.
- «Расширенный режим» в настройках открывает доступ ко всем экранам классического интерфейса.
- Код нового интерфейса изолирован от кода upstream (`throneproj/ThroneForAndroid`): отдельный source set и пакет, правки исходных файлов upstream ограничены перечисленными в design.md точками.
- Не меняется: ядро и `THRONE_CORE_REF`, поддерживаемые протоколы, модель данных и формат резервных копий, экраны классического интерфейса.

## Capabilities

### New Capabilities
- `simple-ui`: упрощённый интерфейс — выбор интерфейса и переключение на классический, навигация и адаптивность, главная, добавление серверов, список серверов, сведения о подписке, настройки и расширенный режим.
- `traffic-modes`: режимы трафика (Авто, Умный, Белые списки, Только выбранные приложения), определение белых списков в сети, распознавание серверов для белых списков, политика автовыбора сервера и обновление списков проверок.
- `connection-repair`: функция «Починка» — набор и порядок проверок, автоматические исправления и их откат, итоговый вердикт и экспорт отчёта.

### Modified Capabilities
- `i18n`: строки нового интерфейса живут в отдельном базовом файле `app/src/simple/res/values/strings_simple.xml` (английский) и переводятся только на русский (`values-ru/strings_simple.xml`); остальные языки используют английский текст через штатный откат Android. Скрипт `tools/diagnostics/i18n_coverage.py` проверяет полноту и форматные плейсхолдеры русского перевода этого файла.
- `repository-governance`: добавляется требование изоляции кода нового интерфейса от кода upstream и проверяемый перечень допустимых точек правки.

## Impact

- Затрагивается только Android-приложение; ядро throne, `THRONE_CORE_REF` и схема sing-box не меняются.
- Сборка: подключаются Jetpack Compose (плагин компилятора Compose для Kotlin 2.0.21, Compose BOM, Material 3, `material3-adaptive`, `material3-adaptive-navigation-suite`, `activity-compose`). Ожидаемый рост APK — несколько МБ на ABI; фактическое значение фиксируется в первом батче.
- Правки файлов upstream (полный перечень — design.md): `app/build.gradle.kts`, `build.gradle.kts`, `app/src/main/AndroidManifest.xml`, меню и обработчик классического бокового меню, точка подключения наблюдателя сети в сервисе `:bg`, точка вызова обновления конфигурации рядом с обновлением маршрутных профилей.
- Новые файлы: `app/src/simple/**` (код, ресурсы, ассеты), строки нового интерфейса только на английском и русском (`values/strings_simple.xml`, `values-ru/strings_simple.xml`), `tools/diagnostics/upstream_touch_points.py`.
- Локализация: новый интерфейс поддерживает только английский и русский; при другом языке системы он показывается на английском. Классический интерфейс сохраняет все 19 переводов.
- Сеть: проверки белых списков и «Починка» делают HTTPS-запросы к фиксированному списку российских и зарубежных адресов в обход туннеля — только при подключении, смене сети, периодически в мобильной сети при включённом VPN и при запуске «Починки». Никакие данные не отправляются с устройства автоматически.
- Внешние источники: набор `Profile_Russia` (запись `Bypass_Russia`) из `throneproj/routeprofiles`; файл конфигурации проверок и ключевых слов в этом репозитории (раздаётся через зеркало rule-set так же, как маршрутные профили).
- Затронутые существующие спецификации: `i18n`, `repository-governance` (изменяются); `proxy-connection`, `routing-rules`, `auto-selector`, `connectivity-testing`, `diagnostics-logging`, `profile-management` — используются как есть, их требования не меняются.
