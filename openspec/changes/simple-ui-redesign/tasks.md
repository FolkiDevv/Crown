Wi-Fi без ограничений → «Авто · умный режим» (`allowed 4/4, blocked 4/4 -> normal`); мобильная сеть с белыми списками → результат проверки через ~2 с, карточки «Авто · белые списки» (цвет предупреждения) и «Сервер для белых списков · Работают в этой сети: N из M» через 4–8 с (с частично доступными разрешёнными адресами — повтор через 3 с, ~10–12 с), сайты открываются через белосписочный сервер (проверка соединения классики); возврат на Wi-Fi → умный режим за 3–7 с; уведомлений о смене нет (только уведомление сервиса VPN); проверка по таймеру 15 минут в мобильной сети; при выключенном VPN смена сети и выбор «Авто» запросов не вызывают (ни строк проверки в журнале, ни соединений в журнале прокси), при подключении — ровно одна проверка; запросы только к восьми адресам конфигурации. Гонка Wi-Fi → мобильная сеть с белыми списками (12 + 8 попыток): результат Wi-Fi отброшен (`cancelled, its result is discarded`) или признан неубедительным (`inconclusive, checking again`, сеть пропала во время проверки), итог — «Авто · белые списки». Ручной выбор «Белые списки»/«Умный» во время проверки сохраняется (`discarded, the mode was changed by the user`), повторный выбор «Авто» запускает новую проверку; выбранный вручную сервер не меняется; сеть без ответа (`no_internet`) режим не меняет.
